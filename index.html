Personal project

Cipher App

A cipher/encoding app that translates Arabic and English text into a custom hieroglyphic-style symbol set and back again — two non-overlapping maps covering 61 unique symbols in total, with a custom dark, monospace-styled interface. All cipher logic is plain Dart, with no external dependencies.

  • Encodes and decodes both Arabic and English text
  • Two non-overlapping cipher maps, 61 unique symbols
  • Custom dark purple/cyan, monospace-inspired UI
  • No external packages — all logic built with plain Dart Map objects

Hardest part: refactoring from an English-only build to properly support Arabic text, while learning new widgets along the way.
